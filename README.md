# InventarioRiwi
Aplicaicon de consolo para el manejo de productos de los inventarios Riwi

## Entrada de datos (variables en Python):
Se realizo la captura de datos de las variables: nombre, precio y cantidad

## Task 2: 
Es esta tarea se implemento la captura de datos ingresados por el usuario en relación al nombre, precio y cantidad
Los datos capturados son:
 - Nombre del prodcuto (Tipo String)
 - Precio unitario (Tipo Float)
 - Cantidad del prodcuto (Tipo Int)
 Se aplico los condicionales if para garantizar la validez de los datos
 Se aplico aplico ciclos "while" que solicita nuevamente la informacion si el usuario digita un valor incorrecto
